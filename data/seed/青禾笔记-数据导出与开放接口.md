# 青禾笔记 · 数据导出与开放接口

## 一、全量导出

团队拥有者和管理员可在「团队设置 → 数据管理 → 导出」发起全量导出。
导出格式支持 Markdown 压缩包、HTML 快照和 JSON（含文档树与元数据）三种。
导出任务异步执行，完成后通过站内通知和邮件告知下载地址，下载地址有效期 72 小时，过期需重新发起。

导出频率限制：免费版每 30 天 1 次，标准版每 7 天 1 次，专业版及以上每天 1 次。
导出期间不影响正常编辑，但导出的是发起时刻的快照。

## 二、单篇导出

单篇文档可导出为 Markdown、PDF、Word（.docx）。
PDF 导出保留知识图谱连线，但会丢失折叠块内的批注；需要保留批注请选择 HTML 导出。
PDF 导出的页边距、字体、是否包含页眉页脚，可在「个人设置 → 导出偏好」中预设。

## 三、开放接口概览

开放接口基于 REST，根地址为 `https://api.qinghe.example.com/v1`，所有请求需在 Header 中携带 `Authorization: Bearer <token>`。
Token 在「团队设置 → 开发者 → API 令牌」创建，权限可选只读或读写，创建后仅显示一次，请立即保存。

主要端点：

- `GET /spaces` 列出团队下的所有空间
- `GET /spaces/{space_id}/documents` 分页列出文档，默认每页 50 条，最大 200 条
- `GET /documents/{doc_id}` 获取文档正文与元数据
- `POST /documents` 创建文档
- `PATCH /documents/{doc_id}` 更新文档标题或正文
- `DELETE /documents/{doc_id}` 归档文档（不物理删除，30 天内可恢复）

## 四、限流与错误码

接口限流为每令牌每分钟 120 次请求，突发允许 20 次。超限返回 HTTP 429，响应头 `Retry-After` 给出建议等待秒数（默认 30 秒）。

常见错误码：

- 401：Token 无效或已吊销
- 403：Token 权限不足，或访问了非本团队资源
- 404：资源不存在或已被归档
- 409：并发写冲突，需重新拉取最新版本再提交
- 422：参数校验失败，响应体会指明具体字段
- 429：触发限流

## 五、Webhook

专业版及以上可配置 Webhook，支持事件：`document.created`、`document.updated`、`document.archived`、`member.joined`。
投递采用至少一次语义，失败重试 5 次，间隔依次为 10 秒、1 分钟、5 分钟、30 分钟、2 小时。
接收端需在 5 秒内返回 2xx，否则视为失败；建议先落库再异步处理，避免重复投递造成重复写入。
签名校验使用 Header `X-Qinghe-Signature`，算法为 HMAC-SHA256，密钥即创建 Webhook 时生成的 Secret。
